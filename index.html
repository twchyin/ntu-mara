⚔️ SQL skills unlocked
Skill #1 · Read table
SELECT col1, col2 FROM table_name LIMIT 10;
Peek at any table — see its shape, columns, and data types.
Skill #2 · Alias
SELECT col1 AS label FROM table AS t LIMIT 10;
Rename columns and tables in output for cleaner reads.
Skill #3 · Filter rows
SELECT "TRANSACTION_ID", "CLAIM_AMOUNT" FROM insurance_data WHERE "CLAIM_AMOUNT" >= 100000;
Use WHERE to slice data to exactly the rows that matter for your business question.
🕵️ Real-world scenario
Data Audit & Inventory — Insurance Firm

You've just joined as a Junior Data Analyst. Your manager hands you three new databases — Insurance Claims, Employee Records, Vendor Info — with no manual. Your job: profile the data, identify what each row represents, and break down the column types (dates, numbers, text).
